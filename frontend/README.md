# MoneyGraph

Из корня репозитория:

```sh
npm --prefix frontend install
npm --prefix frontend run build
python run_fingraph.py
```

Откройте http://127.0.0.1:8080. Требуются Python-зависимости существующего аналитического движка.
Для разработки: запустите адаптер и `npm --prefix frontend run dev`.

React-интерфейс использует один `/api/dataset`; роли, оценки, координаты и кластеры берутся из существующих результатов. Адаптер не меняет аналитические правила. Все GID преобразуются из int64 в строки в Python, до JSON-сериализации. Дополнительная роль `boundary` соответствует документированному контракту MoneyGraph.

`POST /api/upload` принимает три parquet в JSON/base64, проверяет схемы и агрегаты. `POST /api/analyze` запускает существующий pipeline в отдельном каталоге `.fingraph`. `/api/status` возвращает настоящий статус; `/api/exports/<name>` отдаёт исходный CSV. Сервер слушает только loopback. Загруженный набор активен до перезапуска; сохранённый каталог можно подключить через `--data` и `--out`.

Полные CSV отличаются от экспортов фильтра. Уведомление о скачивании означает передачу файла браузеру: веб-приложение не может подтвердить запись на диск.
